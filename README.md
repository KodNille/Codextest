# Mina subscriptions

En enkel webbapp för att hålla koll på abonnemang och hur mycket de kostar per månad/år.

## Funktioner
- Lägg till abonnemang med namn, kostnad, intervall och kategori.
- Se total kostnad per månad och per år.
- Ta bort abonnemang.
- Sparar data i webbläsarens `localStorage`.

## Kör lokalt
Öppna `index.html` direkt i webbläsaren eller kör en enkel server:

```bash
python3 -m http.server 4173
```

Besök sedan `http://localhost:4173`.
